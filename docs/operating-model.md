# Cloud Operating Model

A landing zone is not only infrastructure. It needs ownership and operational processes.

## Platform responsibilities

- identity and access foundations
- shared connectivity
- policy / governance
- observability
- security baseline
- common automation
- lifecycle management

## Workload responsibilities

- application architecture
- workload-specific monitoring
- data protection
- recovery testing
- deployment pipelines
- application support

## Shared responsibilities

- incident management
- vulnerability remediation
- cost optimisation
- architectural exceptions
- change management
- continual improvement

## Decision principle

Guardrails should make the secure, supportable path easier without creating unnecessary manual gates.
