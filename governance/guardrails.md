# Landing Zone Guardrails

## Identity

- use Entra ID and RBAC
- minimise standing privilege
- separate administrative duties where required
- use managed identities for workloads where supported

## Networking

- define approved network patterns
- avoid accidental public exposure
- centralise shared connectivity where appropriate
- log and monitor security-relevant network events

## Security

- establish Defender for Cloud / security posture management strategy
- use policy for enforceable standards
- centralise security telemetry
- define exception ownership and expiry

## Management

- central logging and monitoring
- consistent tagging
- backup/recovery requirements
- change control for shared platform services

## Cost

- budgets and alerts
- ownership tags
- regular unused-resource review
- architecture choices that consider lifecycle cost
