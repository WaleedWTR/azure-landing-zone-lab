# Tagging Standard

## Required baseline tags

| Tag | Purpose | Example |
| --- | --- | --- |
| environment | lifecycle / environment | dev, test, prod |
| owner | accountable owner | team-platform |
| workload | logical service/workload | payments-api |
| costCentre | financial allocation where used | CC1234 |
| dataClassification | information-handling context | internal |

## Principles

- tags should support operational decisions, not become an uncontrolled metadata dump
- required tags should be enforceable
- values should use agreed vocabulary
- inheritance / automation should be used where appropriate
- tags are not an access-control mechanism
